# Baasveranda Home Page Recreation

Open `index.html` in a browser to use the page.

## Included

- Static homepage with supplied local images
- Responsive desktop and mobile layout
- Mobile navigation menu
- Search modal
- Cart drawer
- Before/after patio slider
- Customer gallery carousel
- FAQ accordion
- Newsletter demo confirmation

## Edit Points

- Page content: `index.html`
- Design and responsive styles: `styles.css`
- Interactions: `script.js`
- Images: `assets/`

The contact details and storefront links are placeholders. Replace them with your own store URLs, email addresses, checkout links, and policy pages before publishing.
